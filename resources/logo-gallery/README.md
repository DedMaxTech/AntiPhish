# Reference images

284 reference images covering 113 brands, obtained from official sites and visually reviewed. Some entries are size or background variants. Each manifest row records the official source, asset URL when available, and provenance. These are reference examples, not a trained or calibrated logo detector. Trademark and third-party image rights remain with their owners; the application MIT license covers code, not third-party logos. No emails or user screenshots are included.

The default geometry detector and web interface use manifest.jsonl through logogallery.py. Operator references in models/logo-references are added with antiphish import-logos PATH; no neural index is required. The optional SigLIP adapter has a separate index and is disabled by default. It is not used to confirm the default graphic matches.
