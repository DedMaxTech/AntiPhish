## Что закончено

- Папка, ZIP и TAR анализируются одним постоянным Analyzer. Есть ID, пути, SHA256, JSON каждого объекта, ошибки, статистика причин и времени, переиспользование дублей, промежуточный JSONL и возобновление совместимых полных результатов.
- Внутренний FastAPI без авторизации: анализ пути/URL и загруженного файла, пакет, история JSON в SQLite, состояние баз, справочник причин. Swagger: /docs. Сервер использует тот же движок решения; брокера заданий и пользовательских ролей нет.
- Linux-пути данных, headless CLI без обязательного Tkinter, выбор Edge/Chromium. Docker и Compose: непривилегированный пользователь, read-only система, временный каталог, том данных и локально опубликованный API.
- Реальные действия PDF, включая сжатый JavaScript; извлечение VBA через oletools в отдельном процессе с ограничением времени/памяти. Добавлены признаки чтения и отправки секретов. Макросы не запускаются.
- Буквальный HTML smuggling и закодированные переходы восстанавливаются статически. Пассивные ресурсы отличаются от навигации. Закрытый HTML dialog, template и неактивные поля не считаются активным запросом пароля.
- QR: одиночный резервный детектор после мультидетектора, инверсия, контраст и бинаризация; проверяются также browser-снимки.
- После зависшего JS завершаются только собственные процессы браузера, а драйвер остаётся работоспособным. Синтетический пароль/OTP не передаётся ни через POST, ни через GET.
- Каталог расширен с 75 до 126 активных идентичностей. Добавлены российские банки, страхование, магазины, доставка, работа и поездки, а также часть зарубежных брендов корпуса. Неустановленные домены не активируются.
- Непроверенный CSV нормализован в отдельную SQLite: 22 853 точных хоста. Это справочный контекст, а не разрешение секретного collector и не основание безопасного вердикта.
- Уточнены предупреждения для поддельных платежей, завершения перевода, восстановления аккаунта на пользовательском хостинге и доступа к документам. Убрана ложная тревога от обычной комбинации минифицированного JS и перехода.
- В отчётах есть этапы времени, версии библиотек, отпечаток исходников/каталога, состояние моделей/баз, DOM с вложенностью, типы ресурсов, XPath и безопасное описание формы. PARTIAL учитывает недоступность запрошенной сети/модели; уже доказанный PHISHING не отменяется.
- Оценка manifest.jsonl: строгий PHISHING отдельно от PHISHING+SUSPICIOUS, разрезы по группам/языкам/источникам, полнота, Wilson 95%, парный bootstrap по группам. Повреждённый объект остаётся FAILED в знаменателе.
- Аудит корпуса и текущих URL создаёт очередь пересмотра, фиксирует даты и снимки. HTTP-доступность отличается от ошибки сохранения снимка.
- Для альтернативной локальной мультимодальной модели есть параметр пути. Экспериментальный multilingual mmBERT скачан в закреплённой ревизии; работает только как дополнительная оценка и по умолчанию выключен.
- Для логотипов работает индекс проверенных изображений на SigLIP2, поиск кандидатов и областей. Проверена галерея из трёх официальных favicon. Новая нейросеть-детектор логотипов не обучалась.

Два независимых контура и новый отдельный экспорт обобщённых правил не создавались, согласно последнему решению пользователя.

## Модели и логотипы

Granite URL QLoRA рассматривает только строку URL. В карточке внешний FPR 64%,
recall 72,8%. В основной вердикт не подключён.
Источник: https://huggingface.co/bengoldberg0/granite-4.2-3b-phishing-url-qlora

Horizon-Labs: multilingual mmBERT 307M, три класса, 384 токена.
Закреплённая ревизия: f1dddff04e7f56dc9f0f068d4e7f0383c583e392.
На 540 при P(fraud)>=0,5: 8/40 и 0/500; при 0,9 — 3/40.
37,7 с с загрузкой. Это не улучшение над основным движком, эксперимент выключен.
Spam не объединяется с fraud. Файл: text-model-zero-shot.json.
Источник: https://huggingface.co/Horizon-Labs/phishing-scam-detector-base

Qwen остаётся извлекателем фактов и точных цитат. Альтернативный путь:
ANTIPHISH_LLM_MODEL_DIR. Gemma и другие альтернативные веса не проверялись.
Сравнивать нужно на одинаковых новых кампаниях, русской легитимной почте,
сохранённых страницах и одинаковом вычислительном бюджете.

SigLIP2 позволяет сопоставлять эталоны без обучения с нуля. RTX 4080 достаточно
для небольшого детектора областей, но нужны рамки, варианты русских логотипов,
партнёрские знаки, значки оплаты и сторонний вход в отрицательных примерах.
Сейчас галерея: Dr.Web, Яндекс, Росгосстрах. Сопоставление картинки с самой собой
проверяет загрузчик, не качество. Визуальный кандидат не является доказательством подмены.
